# İsteğe bağlı Blackbox decoder

Uygulama uyumlu `.BFL` ve `.BBL` kayıtlarını kendi çözücüsüyle okuyabilir. Bazı Betaflight sürümleri veya ayrıntılı kayıt alanları için resmi `blackbox_decode` gerekebilir.

[betaflight/blackbox-tools](https://github.com/betaflight/blackbox-tools) projesinden uygun `blackbox_decode.exe` dosyasını edinip bu klasöre koyabilirsin. Uygulamaya dahil değildir.
